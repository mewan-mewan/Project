# My Website Project

## About the Project
This is a web-based application developed as a university project.

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Features
- User Login
- Database Connectivity
- User-Friendly Interface

## How to Run
1. Install XAMPP.
2. Copy the project folder into the `htdocs` folder.
3. Start Apache and MySQL.
4. Import the database into phpMyAdmin.
5. Open the project using `http://localhost/project/`.
